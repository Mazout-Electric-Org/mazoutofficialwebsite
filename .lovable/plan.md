

# Mazout Electric — Zooty Platform Website

## Design System
- **Dark theme**: Near-black background (#0a0a0f) with subtle blue/cyan gradients
- **Accent colors**: Electric cyan, deep blue, subtle white
- **Typography**: Large, bold headings (Inter/system font), minimal body text
- **Grid/system aesthetic**: Abstract dot grids, concentric circles (atom-inspired), layered translucent panels

## Page Structure & Sections

### 1. Hero Section
- Full-viewport dark canvas with animated particle/atom grid background
- Bold headline: *"The Operating System of Urban Movement"*
- Subtle glowing Zooty silhouette/wireframe
- Two CTAs: "Partner With Us" / "Enquire Now"
- Smooth fade-in on load

### 2. Problem Statement
- Split layout with sharp stats/declarative statements
- "Fragmented. Inefficient. Unsustainable." with supporting micro-copy
- Abstract broken-grid visual representing urban chaos

### 3. Thesis — Why Micro-Mobility, Why Now
- Minimal text blocks with strategic insight
- Timeline-style progressive reveal
- Atom-inspired orbital diagram showing convergence of trends

### 4. Zooty Platform (System Stack)
- Layered visual stack: Hardware → Software → Data → Intelligence
- Each layer reveals on scroll with hover interactions
- Abstract system diagram aesthetic (not product photo)
- Technical specs as clean data points

### 5. Applications / Use Cases
- Four modular cards: Logistics, Patrolling, Bike Taxi, Custom
- Same platform, different deployments — shown as configurable modules
- Subtle icon system, minimal text

### 6. Technology Deep Dive
- Modular architecture diagram with animated data/control loops
- Grid-based layout showing scalability
- Technical credibility without clutter

### 7. Trials & Validation
- Horizontal timeline with pilot milestones and metrics
- Clean stat counters (km tested, units deployed, etc.)
- Compliance badges/indicators

### 8. Vision
- Full-width cinematic section
- "Autonomous. Networked. Global."
- Abstract visualization of networked mobility nodes
- Progressive parallax reveal

### 9. Final CTA
- Dark gradient section with strong partnership push
- "Build the future of urban movement with us"
- Contact form or enquiry button

### 10. Footer
- Multi-column: Blogs, Careers, Contact, Buy Now, Gallery, Policies, Docs, Dashboard
- Social links, copyright
- Minimal, structured

## Interactions & Animations
- Scroll-triggered fade/slide animations per section
- Parallax depth on hero and vision sections
- Hover effects on platform stack layers and use case cards
- Smooth cinematic scroll behavior
- Subtle particle/grid background animations

## Pages
- Single-page scrolling experience (Index)
- All sections on one page with smooth navigation
